# CUDA Preview Recording

The former Python preview recorder has been removed with the Python server. The native core still supports `--stream-hexapod-preview`, but there is no dedicated preview recording command.

Use `make local-client-record` to record the live simulation to `local_client/animation.mp4`. Install FFmpeg first. See [Rust recording options](../../local_client/README.md).
