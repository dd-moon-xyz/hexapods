# Credits

The custom CUDA hexapod renderer implements six-arm gait, fluid trails, contact injury, and GPU composition for this project.

The repository originated as a fork of DeepQuantum’s project, based on work by Bert Wang-Chak Chan. This attribution records the source project's provenance; the current application runs only the custom hexapod simulation.
